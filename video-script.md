# GitHub and npm Security Response in 2026 — 50-Second Presentation

“Talking about how GitHub and npm are improving software supply-chain security in 2026.

First, npm introduced malware scanning for newly published packages, helping detect malicious software before it becomes available for installation.

Second, GitHub added protections that can hold suspicious GitHub Actions workflows until a human reviews and approves them.

Third, GitHub improved the security of pull_request_target workflows by making actions/checkout safer by default. This helps prevent untrusted pull-request code from running with privileged repository access.

Overall, these changes help stop attacks earlier, protect sensitive credentials, and make software development more secure.”
